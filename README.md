# Simple Interest Calculator

This repository is created for the final project of the **Getting Started with Git and GitHub** course offered by IBM on Coursera.

## Project Description

This project provides a simple Bash script that calculates simple interest based on three input values:

- Principal amount (P)
- Annual interest rate (R)
- Time period in years (T)

The script calculates simple interest using the following formula:

**Simple Interest = (P × R × T) / 100**

## How to Run

1. Clone this repository to your computer.
2. Open a terminal in the project folder.
3. Run the following command:

`bash simple-interest.sh`

4. Enter the principal amount, annual interest rate, and time period when prompted.

## Example

Input:

- Principal: 1000
- Annual interest rate: 5
- Time: 2 years

Output:

`Simple Interest: 100`
